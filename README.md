# Main Street Fantasy Football

A modern fantasy football web application built with React, TypeScript, and Tailwind CSS.

## Features

- **Live Scoring Dashboard** — Real-time score updates for all matchups with win probability tracker
- **Draft Room** — Full snake draft module with countdown timer, player search/filter, and auto-pick
- **AI Suggestions** — AI-generated waiver, start/sit, trade, and matchup tips with confidence scores
- **Team Management** — Manage your roster, view player stats, and browse the waiver wire
- **Standings** — League standings table with playoff position indicators and weekly matchup results

## Tech Stack

- [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev) for fast development and builds
- [Tailwind CSS v4](https://tailwindcss.com) for styling
- [React Router v7](https://reactrouter.com) for client-side navigation
- [Lucide React](https://lucide.dev) for icons

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).
